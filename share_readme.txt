================================================================
  실시간 선석 모니터링 (BerthMonitor)
================================================================

[ 실행 방법 ]

 1. 이 압축파일을 폴더째로 풀어주세요.
    (바탕화면이나 C:\ 아래 아무 데나 괜찮습니다)

 2. 폴더 안의  BerthMonitor.exe  를 더블클릭하면 실행됩니다.
    설치 과정은 없습니다. 지우고 싶으면 폴더째로 삭제하면 끝입니다.

 !! 주의 : exe 파일만 따로 꺼내서 옮기면 실행되지 않습니다.
           같은 폴더의 _internal 폴더가 함께 있어야 합니다.
           바로 실행하고 싶으면 exe 에 마우스 오른쪽 →
           "바로 가기 만들기" 로 바탕화면에 바로가기를 두세요.


[ 실행할 때 경고창이 뜨는 경우 ]

 · "Windows의 PC 보호" 파란 창이 뜨면
      → [추가 정보] 클릭 → [실행] 버튼

 · 백신이 위험/의심 파일이라고 잡는 경우
      → 오탐(잘못된 탐지)입니다. 바이러스가 아닙니다.
        Python 으로 만든 프로그램을 exe 로 묶으면 백신이
        내부 구조를 못 읽어서 종종 이렇게 잡습니다.
        백신에서 "허용" 또는 "예외 추가" 해주시면 됩니다.
        찜찜하시면 www.virustotal.com 에 파일을 올려보세요.


[ 프로그램 설명 ]

 부산 · 인천 · 광양 주요 터미널의 선석배정 현황을 자동으로 모아
 간트 차트로 보여줍니다. 우리 선사 관련 선박만 걸러서 나옵니다.

  - 조회 터미널 : 신선대 / 감만 / 허치슨 / 광양서부 /
                  E1CT / 한진신항 / 선광신항
  - 표시 구간   : 오늘 00:00 부터 7일간
  - 자동 갱신   : 실행 중 주기적으로 다시 조회합니다.
                  (오른쪽 위 [새로고침] 으로 즉시 갱신)
  - 빨간 세로선 : 현재 시각 (1분마다 이동)
  - 막대에 마우스를 올리면 선명 / 항차 / 작업예정 시간과
    항로(LANE·ROUTE·운항선사) / 행선지가 나옵니다.
  - 막대 앞의 색점 : 분홍 = 일본행, 보라 = 중국행
                     (편성표에 등록된 선박만 표시됩니다)

 탭으로 전체 / 부산 / 인천 / 광양 / 본선작업현황 / 국내공컨현황을
 나눠서 볼 수 있습니다.


[ 안 될 때 ]

 · 화면이 비어 있고 "오류 N건" 이 보이면 터미널 사이트가
   일시적으로 안 열리는 경우가 많습니다. 잠시 뒤 새로고침 해보세요.
 · 회사 내부망 방화벽에서 터미널 사이트를 막으면 조회가 안 됩니다.
 · 인터넷 연결이 필요합니다.
